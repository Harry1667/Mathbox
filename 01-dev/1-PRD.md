## 1. 產品概述 (Project Overview)
* **核心價值**：打造純前端、本地優先 (Local-First)、支援高品質 LaTeX 數學排版與符號運算的工程公式儀表板。解決理工學生死記公式、解決複雜方程與單位轉換的痛點。
* **目標對象**：理工科系學生、科研人員、以及需要快速驗證數值的工程師。
* **使用情境**：實驗結報撰寫、考試準備、複雜物理/工程參數快速代入求解，以及利用 AI 助手快速理解公式背後的物理意義。

## 2. 系統架構與技術建議 (Tech Stack for AI)
* **前端呈現與數學渲染**：React (建議使用 Vite 建立) + Tailwind CSS (負責快速排版與深淺色模式) + KaTeX (`react-katex`，支援學術級 LaTeX 語法渲染) + Framer Motion (處理平滑動畫)。
* **後端 API 伺服器**：Node.js (Express) 擔任輕量級後端，負責接收前端請求並處理資料庫讀寫。前後端統一使用 JavaScript，能大幅降低 AI 在生成全端代碼時的上下文混亂與語法錯誤。
* **資料庫與狀態管理**：後端採用 SQLite (輕量級實體檔案資料庫) 永久保存使用者的個人筆記與自訂公式；前端使用 Zustand (全域狀態管理) 搭配 Axios (網路請求套件) 進行跨組件的資料流動與 API 串接。
* **運算引擎**：前端計算邏輯導入 `mathjs` 函式庫，取代原生的 `eval()` 執行數學計算，以解決 JavaScript 浮點數誤差並避免 XSS 資訊安全漏洞。
* **部署方式建議**：基於自備網域與 aaPanel 伺服器進行「前後端分離部署」。前端打包為靜態檔案透過 Nginx 託管，後端 API 透過 aaPanel 內建的 Node.js 專案管理器常駐運行，並利用反向代理 (Reverse Proxy) 串聯前後端請求。

## 1. 產品概述
這是一個專為工程師與學生設計的互動式公式管理與計算平台。使用者可以管理預設公式、新增自訂公式，並透過直觀的 LaTeX 渲染介面直接進行數值計算與符號求解。

## 2. 核心計算邏輯 (Calculation Logic)

### 2.1 符號求解 (Symbolic Solving)
- **引擎**: 使用 `mathjs` 進行數值運算，結合 `nerdamer` 進行符號代數求解。
- **邏輯**: 
    - 使用者必須在公式的所有變數中**留空一個**作為目標（Target Variable）。
    - 系統將公式轉換為 `(左式) - (右式) = 0` 的形式。
    - 將已填寫的數值代入公式，利用 `nerdamer().solveFor()` 解出留空的變數。
    - 最後使用 `math.evaluate()` 將結果轉換為高精度的數值並格式化顯示。

### 2.2 變數偵測與解析
- **自動偵測**: 在新增公式時，系統會透過正則表達式（Regex）解析 LaTeX 字串，自動提取變數符號（如 $J_s, I, w$）。
- **過濾機制**: 自動過濾 LaTeX 命令（如 `\frac`, `\pi`, `\sin`）以及常見數學常數。
- **公式轉換**: 系統會嘗試將 LaTeX 語法自動轉換為 `mathjs` 可執行的運算式（例如 `\frac{a}{b}` 轉為 `(a/b)`）。

### 2.3 共享變數 (Shared Variables)
- **全局池**: 系統維護一個共享變數池，當一個公式計算出結果後，該符號的數值可以被其他含有相同符號的公式參考（實作於 `SharedVariablesContext`）。

## 3. 介面設計 (UI/UX Design)

### 3.1 公式卡片 (Formula Card)
卡片分為兩種狀態：**收合 (Collapsed)** 與 **展開 (Expanded)**。

#### **收合狀態 (預覽模式)**
- **Header**: 顯示學科標籤（如：電子學）、自訂標籤（如：重要）。右側有展開按鈕與右鍵選單。
- **內容**: 
    - 中英文標題（如：表面電流密度 / Surface Current Density）。
    - **LaTeX 渲染區**: 使用 KaTeX 渲染的高品質數學公式。
    - 簡短描述與個人筆記預覽。

#### **展開狀態 (計算模式)**
- **互動式公式**: 
    - 將 LaTeX 公式與 Input 輸入框結合。使用者直接在公式對應的位置輸入數值。
    - 輸入框會根據內容長度自動伸縮。
- **計算按鈕**: 點擊後執行求解邏輯。
- **結果反饋**: 計算出的數值會以綠色加粗顯示在對應的輸入框中。
- **個人筆記編輯**: 提供文字區域供使用者記錄心得，支援自動儲存。

### 3.2 側邊欄 (Sidebar)
- **分類導覽**: 按學科（物理、微積分、電子學等）過濾。
- **資料夾系統**: 支援多層級資料夾歸類。
- **搜尋功能**: 即時過濾標題、描述或 LaTeX 內容。

### 3.3 主題系統 (Theming)
- **白天模式**: 清爽的灰白配色，藍色作為強調色。
- **深色模式**: 深灰色背景（Gray-950），高對比度文字，優化長時間使用的視覺疲勞。

## 4. 操作流程 (Operational Workflow)

### 4.1 新增公式流程
1. 點擊右下角 `+` 按鈕開啟「新增公式彈窗」。
2. 輸入中文名稱、英文名稱並選擇分類。
3. **輸入 LaTeX**: 系統即時渲染預覽，並自動偵測變數。
4. **檢查方程式**: 系統自動生成運算邏輯，使用者可手動微調（如 `F = m * a`）。
5. **定義變數**: 為偵測到的符號設定名稱（如 $m$ 為「質量」）與單位（如 `kg`）。
6. 儲存後，新公式即出現在儀表板。

### 4.2 計算操作流程
1. 在儀表板找到目標公式，點擊展開。
2. 在公式中的輸入框填入已知數值。
3. **保留一個目標變數為空**。
4. 點擊「計算結果」。
5. 系統顯示結果，若有錯誤（如填寫不完整或語法錯誤）會顯示紅字提示。

### 4.3 管理與備份
- **右鍵選單**: 在卡片上點擊右鍵可快速進入編輯名稱、編輯公式、編輯標籤或刪除。
- **系統設定**: 
    - 切換深色模式。
    - **資料備份**: 將所有自訂公式匯出為 JSON 檔案。
    - **資料還原**: 上傳 JSON 檔案恢復之前的公式庫。
    - **重置系統**: 清空所有資料恢復預設狀態。

## 4. 使用者操作流程 (User Flow)
* **Step 1**：使用者進入網頁，系統觸發初始化，從 LocalStorage 讀取主題偏好 (深色/淺色) 與自訂資料，並渲染預設的公式卡片牆。
* **Step 2**：使用者透過頂部搜尋列輸入目標公式關鍵字，篩選出特定卡片並點擊展開動態計算器。
* **Step 3**：使用者在動態生成的輸入框中填寫數值，或利用內建微型轉換器將非標準單位轉換為國際標準單位，系統進行即時防呆檢查。
* **Step 4**：點擊「計算」後，系統顯示最終數值、單位以及運算步驟，並將此紀錄存入側邊欄，使用者可點擊「複製結果」完成任務。

## 5. 邊界條件與防呆機制 (Edge Cases)
* **輸入無效**：當留空的變數超過一個或全部填滿時，計算按鈕轉為警告提示。
* **無解情況**：若 nerdamer 無法解出符號解，系統提示「方程式在目前輸入下無實數解」。
* **LaTeX 報錯**：自定義公式時，若 LaTeX 語法錯誤，即時預覽區顯示錯誤提示而非崩潰。
* **資料全毀**：提供「重設系統資料」按鈕，快速恢復至初始乾淨狀態。
