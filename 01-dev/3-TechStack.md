# 工程公式與定理速查儀表板與計算器 技術棧評估與建議文檔 (本地優先版)

## 1. 專案技術需求總覽 (Tech Overview)
* **核心技術需求**：需要高互動性的純前端介面處理動態變數表單與 KaTeX 數學渲染；同時需具備後端 API 伺服器，負責與 SQLite 檔案資料庫進行安全的讀寫互動；最終需部署至自備的 aaPanel 伺服器與專屬網域。
* **AI 生成友善度要求**：中高難度（從純前端升級為全端）。雖然你有伺服器管理經驗，但對於「依賴 AI 生成代碼」的環節來說，專案複雜度已翻倍。AI 必須同時處理前端畫面渲染與後端資料庫邏輯，極易在對話上下文中產生「前後端邏輯混淆」的幻覺。

## 2. 前端技術棧 (Frontend)
* **React (Vite) + Tailwind CSS + Framer Motion**
    * **新手難度**：中
    * **新手常見難點/坑**：Node.js 環境安裝與終端機指令對初學者較陌生；React 的「狀態 (State)」與「非同步 API 請求 (useEffect)」概念容易讓 AI 生成無限迴圈的代碼，導致瀏覽器當機。
    * **優點**：AI 生成 React 代碼的能力封頂。元件化設計（卡片、搜尋列獨立）能確保專案變大時，AI 修改 A 功能不會弄壞 B 功能。
    * **缺點**：初始學習成本較高，需學會看懂 Vite 的啟動與打包 (Build) 錯誤訊息。

## 3. 後端與資料庫技術棧 (Backend & Database)
* **Node.js (Express) + SQLite 3**
    * **新手難度**：中高
    * **新手常見難點/坑**：
        * **CORS (跨域資源共用) 報錯**：前端與後端分屬不同網址或 Port 號時，瀏覽器必定阻擋請求。新手經常不知道要請 AI 在 Express 中加上 `cors` 中介軟體。
        * **非同步鎖死**：SQLite 是單一檔案資料庫，若 AI 沒有寫好非同步 (Async/Await) 邏輯，高頻率的連續寫入可能會造成資料庫鎖定 (Database is locked)。
    * **優點**：前後端都使用 JavaScript/TypeScript 語言。這對 Vibe Coding 非常重要，因為 AI 在同一個專案語境下不需要在兩種程式語言間頻繁切換大腦，生成的語法與變數命名會更一致。
    * **缺點**：對於完全沒寫過後端的新手，API 路由 (Router) 的概念較為抽象。

## 4. 部署與託管平台 (Hosting & Deployment)
* **自備網域 + aaPanel (Nginx 靜態網站 + Node.js 專案管理器)**
    * **新手難度**：中
    * **新手常見難點/坑**：
        * **反向代理 (Reverse Proxy) 設置**：前端 React 打包後的靜態檔放在 Nginx 下很簡單，但後端 Express 通常跑在 `http://127.0.0.1:3000`。新手需在 aaPanel 設定反向代理，將 `/api` 結尾的請求正確轉發給後端，這一步 AI 只能給設定檔範例，需靠使用者自己在圖形介面操作。
        * **環境變數 (ENV) 遺失**：本機開發時連線到 `localhost`，上線後要連線到真實網域。新手常忘記請 AI 拆分 `.env` 檔案，導致部署後前端找不到後端 API。
    * **優點**：資料庫實體檔案 (`.sqlite`) 完全掌握在自己手裡，無須擔心如 Vercel 等 Serverless 平台會定時清空暫存檔案的問題。
    * **缺點**：伺服器維護、SSL 憑證更新與服務器崩潰重啟都必須自己透過 aaPanel 處理。

## 5. 必備第三方工具與 API (Third-Party Tools & APIs)
* **`react-katex` (前端數學渲染引擎)**：
    * **用途**：將後端傳來的 LaTeX 字串渲染成公式（例如 $E = m c^2$）。
    * **難度與注意事項**：需特別提醒 AI 處理資料庫讀取出來的「跳脫字元 (Escape Characters)」，否則反斜線 `\` 存入 SQLite 再拿出來時容易遺失，導致公式破圖。
* **`axios` (前端網路請求套件)**：
    * **用途**：負責讓 React 前端向 Node.js 後端發送 GET/POST 請求。
    * **難度與注意事項**：比起原生的 `fetch`，Axios 的語法對 AI 來說更標準化，且攔截錯誤訊息更精準。請指示 AI 設定全域的 BaseURL 來區分開發與正式環境。
* **`cors` (後端跨域套件)**：
    * **用途**：安裝於 Node.js 後端，允許你的網域前端來索取資料。
    * **難度與注意事項**：零基礎新手最常卡關的魔王。務必在第一天就要求 AI 在 `server.js` 寫入 `app.use(cors())`。
* **`mathjs` (前端安全計算引擎)**：
    * **用途**：代替 JS 原生的 `eval()` 執行數學計算。
    * **難度與注意事項**：絕對不要讓 AI 用 `eval()` 來計算動態代入的變數，除了有浮點數誤差外，還極易產生 XSS 資訊安全漏洞。

## 6. Vibe Coding 實戰策略總結 (Action Plan)
* **最佳技術組合**：**React (Vite)** 負責介面 + **Node.js (Express)** 負責 API + **SQLite** 負責資料儲存 + **aaPanel** 負責生產環境託管。
* **第一階段驗證目標**：因為專案變成全端，**請務必將前後端拆成兩個獨立的資料夾，並開兩個獨立的 AI 對話視窗**。第一步請先放下前端畫面，專心請 AI 幫你建置後端：
  > 「我是一個沒有程式基礎的新手。我現在要開發一個專案的後端 API。請幫我在這個空資料夾中建立一個 Node.js + Express + SQLite 的伺服器。
  > 1. 請幫我安裝必要的套件（包含 `express`, `sqlite3`, `cors`）。
  > 2. 請幫我寫一個初始化資料庫的腳本，建立一個 `formulas` 資料表。
  > 3. 請實作一個簡單的 `GET /api/test` 路由，回傳一段包含 LaTeX 測試字串的 JSON 給我。
  > 4. 請告訴我如何啟動伺服器，並在瀏覽器中看到這支 API 的測試結果？」
