# 👤 用戶操作流程文檔 (User Flow Document)

本文件詳細描述使用者在 **Formula Architect** 中的主要操作路徑與互動邏輯。

---

## 1. 核心操作流程：公式計算 (Calculation Flow)
這是使用者最頻繁使用的流程。

1.  **進入儀表板**：使用者開啟應用程式，看到所有公式卡片。
2.  **尋找公式**：
    *   透過**搜尋列**輸入關鍵字。
    *   或在**側邊欄**選擇特定學科分類（如：電子學）。
3.  **展開卡片**：點擊目標公式卡片右側的展開圖示（或卡片標題）。
4.  **輸入數值**：
    *   在公式渲染區的輸入框中填入已知變數的數值。
    *   **關鍵操作**：必須保留一個目標變數（欲求解的變數）為空。
5.  **執行計算**：點擊藍色的「計算結果 / CALCULATE」按鈕。
6.  **查看結果**：系統自動解出目標變數，並以**綠色加粗**字體顯示在對應的輸入框中。
7.  **紀錄筆記**：使用者可在下方的「個人筆記」區域點擊並輸入心得，點擊「確認」儲存。

---

## 2. 公式管理流程：新增自訂公式 (Creation Flow)

1.  **開啟彈窗**：點擊右下角的浮動 `+` 按鈕。
2.  **填寫基本資訊**：輸入中文名稱、英文名稱，並選擇所屬學科。
3.  **輸入數學式**：
    *   在 LaTeX 區域輸入公式語法（如 `F = m \cdot a`）。
    *   下方會即時顯示渲染預覽，確保語法正確。
4.  **定義變數**：
    *   系統會自動偵測公式中的符號。
    *   使用者需為每個符號定義「顯示名稱」（如：質量）與「單位」（如：kg）。
5.  **檢查運算邏輯**：確認系統生成的 `mathjs` 方程式是否正確。
6.  **儲存**：點擊「Save Formula」，新公式會立即出現在儀表板頂部。

---

## 3. 進階管理流程：編輯與刪除 (Management Flow)

1.  **右鍵選單**：在任何公式卡片上點擊滑鼠右鍵。
2.  **選擇動作**：
    *   **編輯卡片**：修改名稱與簡短描述。
    *   **編輯公式**：修改 LaTeX 語法或計算邏輯。
    *   **編輯標籤**：新增或刪除自訂標籤（如：重要、易錯）。
    *   **刪除公式**：將公式從庫中移除（需確認）。

---

## 4. 歷史紀錄查看 (History Flow)

1.  **開啟歷史**：點擊頂部導覽列的「歷史紀錄」圖示。
2.  **瀏覽紀錄**：右側抽屜開啟，顯示過去所有的計算紀錄，包含輸入值與結果。
3.  **管理紀錄**：
    *   點擊單筆紀錄旁的 `X` 刪除該次紀錄。
    *   或點擊上方的垃圾桶圖示「清空全部」。

---

## 5. 系統設定與維護 (Settings Flow)

1.  **開啟設定**：點擊頂部導覽列的「系統設定」圖示。
2.  **切換主題**：點擊「深色模式」開關，介面即時切換白天/黑夜模式。
3.  **資料備份**：點擊「匯出資料」，下載包含所有自訂公式的 JSON 檔案。
4.  **資料還原**：點擊「匯入資料」，選擇先前備份的 JSON 檔案進行覆蓋。
5.  **系統重置**：若需清空所有自訂內容，點擊「重置系統」並在彈窗中確認。

---

## 6. 異常處理流程 (Error Handling)

*   **計算錯誤**：若使用者填寫的數值不完整（少於一個空位或沒有空位），系統會顯示紅字提示「請留空一個變數作為目標」。
*   **語法錯誤**：若自訂公式的運算邏輯有誤，計算時會提示「計算錯誤，請檢查數值」。
*   **匯入失敗**：若匯入的 JSON 格式不正確，系統會攔截並提示錯誤。
